# Avatar-Forever Project Page

Official project page for **Avatar-Forever: Decoupled Parallel Training for High-Quality Real-Time Infinite Avatars**.

**Website:** https://leeruibin.github.io/avatarforever-project-page/

The first release contains the paper overview, method summary, headline results, author information, and placeholders for forthcoming video demos.

## Updating the demo videos

Add optimized video files under `assets/videos/`, then replace the placeholder cards in `index.html` with HTML `<video>` elements. Prefer MP4/H.264 files with poster images for broad browser compatibility.
